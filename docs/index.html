Programming Prompts — AI coding-agent prompt library

Programming Prompts is a prompt library that provides reusable AI coding-agent prompts and engineering guidance for Codex and Claude Code users.

Plain Markdown prompts you can read before you run them. Source on GitHub

Quickstart

Clone the content source and read a skill directly — nothing is installed and there is no runtime dependency:

git clone https://github.com/mikaeltorni/programming_prompts.git
cd programming_prompts
sed -n '1,120p' skills/general-programming-guidelines/SKILL.md

What is in the prompt library

The catalog separates three kinds of prompt, because they are consumed differently:

Plugins — packaged Codex and Claude Code integrations

  • Commit Guidelines — conventional commit messages and commit hygiene.
  • Linux Desktop Configuration — GNOME Shell, gsettings, and systemd user service rules.

Direct skills — single prompts you load on demand

  • General Programming Guidelines — the engineering workflow: worktree isolation, tests, logging, delivery.
  • Init Project — project initialization with supply-chain protection.
  • Refactoring — behavior-preserving restructuring.
  • Setup Repository Guidelines — repository conventions and scaffolding.

Dispatch skills — hand an agent a repository and nothing else

  • GitHub SEO — scores repository discoverability against a rubric and loops on the gaps.

Using the prompts with Codex and Claude Code

Every plugin directory carries its own .codex-plugin/plugin.json and .claude-plugin/plugin.json manifest plus exactly one skill, so a compatible CLI can install it straight from that directory. Validate one before installing:

claude plugin validate --strict plugins/commit-guidelines

Direct skills under skills/ are prompt-only and carry no manifests — load the SKILL.md in whichever agent you use.

Frequently asked questions

Where should I start with Programming Prompts?

Start with the general-programming-guidelines skill, which carries the shared engineering workflow every other prompt builds on. If you want a packaged Codex and Claude Code integration instead of a single prompt, browse the two plugin directories. Both are plain Markdown you can read before installing anything.

Is this repository a plugin marketplace?

No. Programming Prompts is the content source for plugins and skills only. Marketplace generation and installation are owned by a separate installer repository, so no marketplace catalog is committed here. The plugins still work standalone because each one ships its own Codex and Claude manifests.

Which prompt is used for GitHub SEO audits?

Use the github-seo dispatch skill. It audits a repository against a 100-point rubric, records the result in a tracked scorecard, and loops over the verified gaps until the score stops improving. Dispatch skills are written to be handed to an agent together with nothing but a target repository.

How do I validate a plugin?

Run claude plugin validate --strict against the plugin directory from a checkout with the Claude Code CLI installed. Each of the two plugin directories contains its own Codex and Claude manifests plus exactly one skill, so validation covers the whole unit.

Why is there no install.sh in this repository?

Deployment ownership deliberately lives in the sibling installer repository, which reads these prompts from source. Keeping it out means the skill and plugin content stays independently inspectable, and compatible CLIs can still install a plugin straight from its directory.
