# Temperature

Write `/app/temperature.py` with `run_temperature(command: str) -> str`.

Commands:
- `c2f <c>` — Celsius to Fahrenheit; return `f=<value>`
- `f2c <f>` — Fahrenheit to Celsius; return `c=<value>`

Use `f = c * 9 / 5 + 32` and `c = (f - 32) * 5 / 9`. Raise `ValueError` for
bad commands.

Follow the provided programming skill.
