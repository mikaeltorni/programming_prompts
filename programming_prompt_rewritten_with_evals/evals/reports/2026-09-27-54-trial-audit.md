## Repairs and comparison

The commits skill now ties optional clauses to their containing sentence and rejects a first commit that already implements later commands. The logging skill requires an exit print in a caller that directly returns a helper result. The worktree skill keeps documentation and repair commits on the task branch. The workflow skill reconciles numeric Feature claims with the ledger at handoff. The matching judges clarify sentence boundaries, accept complete inline source evidence, distinguish helper returns from caller exits, and check the actual last statement before claiming implicit fallthrough. A shared judge reliability gate retries a self-contradictory no or an implicit-fallthrough claim contradicted by a final top-level `return`; an unresolved contradiction is classified as infrastructure, not as a scored no.

On the archived 54-trial sample, correcting the four false verdicts would change the all-criteria total from **46/54 to 49/54**: three trials recover fully, while `stats__JRAvqJs` still fails the valid logging criterion. This is an audit adjustment, not a rerun of those historical trials.
