# Document the delivered program

After the program works, write or update the project-root `README.md` with its
purpose, public entrypoint and every accepted command or API form. Include
useful inputs/examples and material usage constraints. This applies to small
scripts and when workflow is unselected; function docstrings are separate.

With feature cycles selected, finish every Feature's verification and commit
before this final README phase. Required function documentation and feature-local
notes still belong with their code.

With worktree selected, author and commit the README in the same task checkout,
then merge and apply it through that workflow. Read the delivered root README
before handoff and confirm it describes the implemented interface.
