# Code of Conduct

## Our standard

Contributors to programming_prompts are expected to be respectful, specific, and constructive. Feedback should address the work, evidence, and user impact rather than people. Harassment, discrimination, doxxing, credential sharing, and deliberate disruption are not acceptable.

## Project-specific expectations

Keep prompts, model outputs, logs, benchmark receipts, and user data appropriately separated. Do not publish secrets or private data while reporting an issue or demonstrating a result.

## Enforcement

Report a conduct concern privately through a GitHub Security Advisory or the repository owner's configured private contact channel. Maintainers may edit, hide, or remove material that violates this code and may restrict participation when necessary.
